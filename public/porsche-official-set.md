# Porsche 911 Turbo · 10295

This public model viewer displays 1,363 physical CAD instances from the community reconstruction by Ulrich Röder (UR). It supports rotation, zoom and model-derived inventories. It is not a build guide and does not certify physical connections, mechanisms or safety.

[Model credits](https://johnson-lee-v0.github.io/LEGO-Collection/official/10295/MODEL-CREDITS.md) identify the author and source. [Provenance](https://johnson-lee-v0.github.io/LEGO-Collection/official/10295/model-provenance.json) records source hashes and adaptations. These assets are excluded from the application's MIT license.

The public release omits the full booklet-derived instruction sequences and callout datasets. Use the original LEGO® booklets, linked from the viewer, for physical assembly. No instruction-page artwork is mirrored.

Catalog crosswalk data is from [Rebrickable Downloads](https://rebrickable.com/downloads/), with attribution retained. The visible model inventory is counted from CAD instances.
